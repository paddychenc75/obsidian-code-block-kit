# Changelog

## 0.1.0

First release.

Added

- Format button and **Format code block at cursor** command, using a bundled Prettier: JavaScript, JSX, TypeScript, TSX, JSON, JSONC, JSON5, CSS, SCSS, Less, HTML, Vue, Markdown, YAML, and GraphQL
- Run button and **Run code block at cursor** command on desktop: Python, JavaScript, and shell, with streamed output, a stop button, a 60 second timeout, and a 200,000 character output limit
- Buttons in both Reading view and Live Preview, lined up beside the copy button or the language label
- Blocks nested in lists and callouts keep their indentation and `>` markers when formatted
